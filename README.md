## Tetris Game by Jokerhut

This is a tetris game i made in C++ using the raylib library.

### Requirements

- CMake 3.16+

- C++20 compiler

### Setup Guide
```bash
git clone https://github.com/jokerhutt/tetris.git

cd tetris-cpp

cmake -B build -DCMAKE_BUILD_TYPE=Release

cmake --build build
```


### Running the Project
```bash
./build/tetris
```

### Keys

- M : Mute/Unmute
- UP : Rotate
- RIGHT : Move block right
- LEFT : Move block left
- DOWN : Move block down
