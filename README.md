## Tetris Game by Jokerhut

This is a tetris game i made in C++ using the raylib library.

### Requirements

- CMake 3.16+

- C++20 compiler

### Setup Guide
```bash
git clone <repo-url>

cd tetris-cpp

cmake -B build -DCMAKE_BUILD_TYPE=Release

cmake --build build```

### Keys

- M : Mute/Unmute
- UP : Rotate
- RIGHT : Move block right
- LEFT : Move block left
- DOWN : Move block down
